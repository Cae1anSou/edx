# NeoEdx 产品需求文档（PRD）

> 本文档基于对 Open edX 平台的逆向分析生成，聚焦于系统行为而非实现细节。

## 一、项目概述

NeoEdx 是一个现代化学习管理系统（LMS）的重构项目，旨在提供完整的在线教育解决方案。该系统支持多角色（学习者、教师、管理员）协作，支持课程创建、内容交付、学习跟踪、成绩评估、证书颁发等核心教育业务流程。

### 1.1 核心目标

构建一个可扩展、可维护的教育平台，支持大规模在线课程交付，具备灵活的内容管理、精确的学习追踪和完善的商业化能力。

### 1.2 目标用户角色

**学习者（Learner）**
- 注册并登录平台
- 浏览和搜索课程
- 按自己的节奏学习课程内容
- 完成作业、测验和项目
- 与同学和助教讨论
- 获得成绩和证书

**课程创作者（Course Author）**
- 创建和编辑课程结构
- 添加和组织学习内容（视频、文本、测验等）
- 配置评估和评分规则
- 管理课程团队成员

**教学团队（Instructor/Staff）**
- 管理课程运行（开课、结课、重跑）
- 监控学生学习进度
- 批改作业和评分
- 与学生沟通（邮件、通知）
- 生成教学报告

**管理员（Administrator）**
- 管理平台配置
- 管理用户和权限
- 配置第三方集成（认证、支付）
- 监控平台运行状态

## 二、核心功能行为

### 2.1 用户管理领域

| 优先级 | 行为 | 描述 |
|--------|------|------|
| P0 | 用户注册 | 访客创建账户，提供基本信息并验证邮箱 |
| P0 | 用户登录 | 已注册用户通过邮箱/用户名和密码登录 |
| P0 | 第三方认证 | 用户可通过 OAuth/SAML/LTI 等方式登录 |
| P0 | 密码重置 | 用户通过邮箱验证重置密码 |
| P0 | 账户恢复 | 用户通过备用邮箱或安全问题恢复账户 |
| P1 | 用户资料管理 | 用户编辑个人资料、头像、姓名等 |
| P1 | 账户退休 | 平台按法规要求删除或匿名化用户数据 |
| P1 | 会话管理 | 用户登录状态管理，支持多设备登录 |
| P2 | 组织用户管理 | 企业/机构用户的批量管理和SSO |

### 2.2 课程管理领域

| 优先级 | 行为 | 描述 |
|--------|------|------|
| P0 | 创建课程 | 课程创作者创建新课程，设置基本信息 |
| P0 | 编辑课程结构 | 创作者组织章节、小节、单元的层级结构 |
| P0 | 添加内容组件 | 创作者添加视频、文本、测验、讨论等学习组件 |
| P0 | 发布课程 | 将课程从草稿状态发布为可见状态 |
| P1 | 课程重跑 | 基于已有课程创建新学期的课程副本 |
| P1 | 课程配置 | 配置课程参数（开始/结束日期、证书、评分策略等） |
| P1 | 课程导入导出 | 导出课程为标准格式或从其他系统导入 |
| P1 | 课程模板 | 基于模板快速创建标准化课程 |
| P2 | 内容库管理 | 创建可复用的内容库，支持跨课程引用 |

### 2.3 学习交付领域

| 优先级 | 行为 | 描述 |
|--------|------|------|
| P0 | 浏览课程目录 | 学习者浏览和搜索可用课程 |
| P0 | 查看课程详情 | 学习者查看课程介绍、大纲、要求 |
| P0 | 课程注册 | 学习者注册/报名课程 |
| P0 | 学习内容 | 学习者按顺序学习课程内容 |
| P0 | 进度跟踪 | 系统记录学习者的学习进度 |
| P0 | 内容导航 | 学习者在课程结构中导航（前进、后退、跳转） |
| P1 | 书签和笔记 | 学习者标记位置、添加个人笔记 |
| P1 | 退出课程 | 学习者取消注册课程 |
| P2 | 学习提醒 | 系统发送学习进度提醒 |
| P2 | 进度计划 | 设置课程截止日期和作业时间线 |

## 三、数据边界

### 3.1 核心数据实体

**用户域**
- 用户账户（唯一标识、认证信息）
- 用户资料（姓名、头像、人口统计信息）
- 用户角色（全局角色、课程角色、组织角色）

**课程域**
- 课程（基本信息、配置、状态）
- 课程结构（章节、小节、单元）
- 内容组件（视频、文本、测验等）
- 课程设置（评分策略、证书配置）

**注册域**
- 课程注册（用户-课程关联、状态、模式）
- 课程模式定义（价格、证书类型）
- 会员资格（用户对课程的长期访问权）

**成绩域**
- 小节成绩（得分、完成情况、时间戳）
- 课程成绩（总评、等级、通过时间）
- 成绩覆盖记录（手工调整原因）

**证书域**
- 证书记录（用户、课程、状态、下载链接）
- 证书模板配置

**讨论域**
- 帖子（标题、内容、类型、状态）
- 评论（内容、嵌套结构）
- 讨论配置（课程级别的讨论规则）

**内容库域**
- 内容库（可复用内容集合）
- 库权限（读者、作者、管理员）
- 内容块（在库中可引用）

### 3.2 数据关系图（行为视角）

```
用户
├── 拥有 账户信息
├── 拥有 资料
├── 持有 角色（全局/课程/组织）
├── 进行 课程注册
│   └── 可关联 会员资格
├── 产生 成绩记录
│   └── 关联 证书
└── 创建 讨论内容
    ├── 帖子
    └── 评论

课程
├── 包含 结构（章节→小节→单元）
│   └── 包含 内容组件
├── 定义 评分策略
├── 配置 讨论规则
└── 关联 证书模板

团队
├── 包含 成员
└── 拥有 讨论区
```

## 四、非功能需求

### 4.1 性能需求

- 支持百万级用户同时在线
- 课程内容加载时间 < 2秒
- 支持高并发的测验提交
- 成绩计算和证书生成异步处理

### 4.2 可用性需求

- 99.9% 系统可用性
- 支持滚动升级
- 故障自动恢复

### 4.3 安全需求

- 用户密码加密存储
- 支持多因素认证
- 数据传输加密
- 符合 GDPR 等隐私法规
- 细粒度的权限控制

### 4.4 可扩展性需求

- 支持插件化扩展
- 易于集成第三方服务
- 支持多租户部署

## 五、范围界定

### 5.1 包含范围（v1）

- 完整的用户认证和授权系统
- 课程创建和管理（基础结构）
- 内容交付（视频、文本、测验）
- 学习进度跟踪
- 成绩计算和展示
- 证书生成
- 讨论区
- 通知系统
- 基础的付费注册流程

### 5.2 暂不包含

- 高级内容库（复杂的内容版本控制）
- 实时视频会议
- AI 助教功能
- 复杂的企业培训集成
- 游戏化学习元素
- 高级分析和预测

## 六、验收标准（行为视角）

### 6.1 用户管理

- [ ] 访客可在 3 分钟内完成注册并收到验证邮件
- [ ] 已注册用户可在 30 秒内登录
- [ ] 用户可通过 Google/Microsoft 账户一键登录
- [ ] 用户可在个人资料页面修改姓名和头像

### 6.2 课程管理

- [ ] 课程创作者可在 5 分钟内创建基础课程
- [ ] 课程创作者可拖拽方式组织章节结构
- [ ] 课程创作者可添加视频、文本、测验组件
- [ ] 课程发布后对已注册学员立即可见

### 6.3 学习体验

- [ ] 学习者可浏览并搜索课程目录
- [ ] 学习者可一键注册免费课程
- [ ] 学习内容按顺序解锁展示
- [ ] 学习进度自动保存

### 6.4 成绩与证书

- [ ] 客观题提交后即时显示分数
- [ ] 主观题成绩在批改后 24 小时内可见
- [ ] 课程成绩在通过后立即可查看
- [ ] 学员可通过唯一链接验证证书

### 6.5 讨论区

- [ ] 学员可创建讨论帖或问答帖
- [ ] 教师可对帖子进行置顶、编辑、删除
- [ ] 新回复通过系统通知用户
