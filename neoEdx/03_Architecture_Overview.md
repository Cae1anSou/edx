### 2.2 核心服务说明

**用户服务（User Service）**
- 处理所有用户相关的认证和授权逻辑
- 提供统一的用户身份管理
- 集成第三方认证提供商
- 管理用户角色和权限

**课程服务（Course Service）**
- 管理课程生命周期
- 暴露课程元数据和配置
- 处理课程发布和归档
- 管理课程重跑

**内容服务（Content Service）**
- 管理课程内容的CRUD操作
- 处理内容版本控制
- 管理内容库和可复用资源
- 提供内容访问接口

**注册服务（Enrollment Service）**
- 处理用户课程注册/取消
- 管理会员资格
- 支持批量注册操作
- 集成商业服务验证支付

**成绩服务（Grade Service）**
- 计算和管理学习者成绩
- 处理成绩覆盖和申诉
- 提供成绩查询接口
- 与证书服务集成

**证书服务（Certificate Service）**
- 基于成绩生成证书
- 管理证书生命周期
- 提供证书验证API
- 处理证书补发和撤销

**讨论服务（Discussion Service）**
- 管理讨论区帖子和评论
- 处理投票和点赞
- 管理帖子审核
- 与通知服务集成

**通知服务（Notification Service）**
- 统一管理多渠道通知
- 处理用户通知偏好
- 批量发送邮件
- 管理邮件模板

**团队服务（Teams Service）**
- 管理学习团队生命周期
- 处理团队成员关系
- 与讨论服务集成
- 支持团队活动跟踪

**商业服务（Commerce Service）**
- 处理订单和支付
- 管理优惠券
- 集成外部支付网关
- 处理退款流程

**实验服务（Experiment Service）**
- 管理A/B测试配置
- 处理用户分组和分桶
- 记录实验数据
- 支持内容分区

**学分服务（Credit Service）**
- 管理学分提供商配置
- 审核学员学分资格
- 处理学分申请流程
- 生成官方成绩单
- 与合作高校系统集成

## 四、跨领域通信模式

### 4.1 同步通信（API调用）

```
┌──────────┐      HTTP/RPC       ┌──────────┐
│  服务A   │ ─────────────────→  │  服务B   │
└──────────┘                     └──────────┘

适用场景：
- 需要即时响应的操作
- 事务性操作
- 查询类请求
```

### 4.2 异步通信（消息队列）

```
┌──────────┐   领域事件    ┌──────────────┐   订阅处理    ┌──────────┐
│  服务A   │ ───────────→ │ Message Bus  │ ───────────→ │  服务B   │
└──────────┘              └──────────────┘              └──────────┘

适用场景：
- 跨服务的状态同步
- 耗时操作的异步处理
- 事件驱动的业务逻辑
```

### 4.3 关键事件流

| 事件 | 产生方 | 消费方 | 说明 |
|------|--------|--------|------|
| UserRegistered | 用户服务 | 注册服务、通知服务 | 新用户注册 |
| CourseEnrolled | 注册服务 | 成绩服务、通知服务 | 用户注册课程 |
| SubmissionReceived | 内容服务 | 成绩服务 | 收到作业提交 |
| GradeCalculated | 成绩服务 | 证书服务、通知服务 | 成绩计算完成 |
| CourseCompleted | 成绩服务 | 证书服务 | 用户完成课程 |
| CertificateGenerated | 证书服务 | 通知服务 | 证书生成 |
| ThreadCreated | 讨论服务 | 通知服务 | 新建讨论帖 |
| TeamMemberJoined | 团队服务 | 通知服务 | 成员加入团队 |

### 5.2 审计日志

- 所有关键操作记录审计日志
- 包含操作人、操作时间、操作类型、操作对象
- 支持按时间、用户、对象类型查询
- 不可篡改的日志存储

### 5.3 监控与可观测性

| 关注点 | 实现方式 |
|--------|----------|
| 日志 | 结构化日志（JSON格式），集中收集 |
| 指标 | 业务指标 + 基础设施指标 |
| 追踪 | 分布式追踪（请求全链路） |
| 健康检查 | 端点健康检查 + 依赖检查 |

### 5.4 缓存策略

| 缓存类型 | TTL | 失效策略 |
|----------|-----|----------|
| 会话缓存 | 24小时 | 主动失效 |
| 配置缓存 | 5分钟 | 事件驱动失效 |
| 内容缓存 | 1小时 | 版本驱动失效 |
| 成绩缓存 | 实时 | 写入失效 |
