## 二、核心领域详细定义

### 2.1 用户域（Identity Domain）

**领域目的**
负责管理平台所有参与者的身份、认证和授权。

**关键行为**
| 行为 | 输入 | 输出 | 前置条件 |
|------|------|------|----------|
| 注册账户 | 用户信息（邮箱、用户名、密码） | 用户账户 | 无 |
| 验证身份 | 验证码/token | 验证结果 | 已注册 |
| 认证登录 | 凭据 | 会话token | 已验证 |
| 授权访问 | 用户+资源+操作 | 允许/拒绝 | 已认证 |
| 分配角色 | 用户+角色+范围 | 角色分配 | 管理员 |
| 撤销角色 | 用户+角色+范围 | 撤销确认 | 管理员 |

**拥有数据**
- 用户账户（UserAccount）
  - 唯一标识符
  - 认证凭据（哈希）
  - 邮箱（唯一）
  - 激活状态
  - 创建/更新时间

- 用户资料（UserProfile）
  - 姓名
  - 头像
  - 人口统计信息
  - 时区/语言偏好

- 角色定义（Role）
  - 全局角色（系统管理员、课程创建者）
  - 课程角色（教师、助教、课程团队）
  - 组织角色（机构管理员）

- 第三方认证配置（ProviderConfig）
  - OAuth提供商
  - SAML配置
  - LTI配置

**外部依赖**
- 外部身份提供商（可选）
- 邮件服务（发送验证邮件）

**非职责**
- 不负责学习内容的管理
- 不负责成绩记录
- 不负责课程配置

---

### 2.2 课程域（Course Domain）

**领域目的**
管理课程的生命周期、结构配置和运行时状态。

**关键行为**
| 行为 | 输入 | 输出 | 前置条件 |
|------|------|------|----------|
| 创建课程 | 课程元数据（名称、代号、组织） | 课程实体 | 课程创建权限 |
| 配置课程 | 配置参数 | 课程配置 | 课程所有者 |
| 发布课程 | 发布操作 | 发布状态 | 课程完成 |
| 归档课程 | 归档操作 | 归档状态 | 课程结束 |
| 重跑课程 | 源课程 | 新课程实例 | 源课程存在 |

**拥有数据**
- 课程元数据（Course）
  - 唯一标识（org+course+run）
  - 名称
  - 说明
  - 开始/结束日期
  - 语言
  - 状态（草稿、已发布、已归档）

- 课程配置（CourseSettings）
  - 评分策略引用（由成绩域解释）
  - 证书策略引用（由证书域解释）
  - 讨论能力开关/引用（引用讨论域配置）
  - 团队能力开关/引用（引用团队域配置）
  - 分组策略引用（引用分组域配置）
  - 进度配置
  - 诚信/监考规则引用（引用诚信监考域配置）

- 课程运行信息（CourseRun）
  - 当前学期/轮次
  - 注册开始/结束日期
  - 最大注册人数

**外部依赖**
- 内容域（获取课程结构）
- 用户域（验证创建者身份）

**非职责**
- 不负责具体内容存储
- 不负责用户注册状态
- 不负责成绩计算

---

### 2.3 内容域（Content Domain）

**领域目的**
管理课程内容的创建、存储、版本控制和组织。

**关键行为**
| 行为 | 输入 | 输出 | 前置条件 |
|------|------|------|----------|
| 创建内容块 | 块类型+数据 | 内容块 | 编辑权限 |
| 更新内容块 | 块ID+新数据 | 更新后的块 | 编辑权限 |
| 删除内容块 | 块ID | 删除确认 | 编辑权限 |
| 组织结构 | 父节点+子节点列表 | 结构树 | 编辑权限 |
| 发布内容 | 内容ID | 发布版本 | 编辑权限 |
| 版本管理 | 内容ID+版本 | 历史版本 | 查看权限 |

**拥有数据**
- 内容块（ContentBlock）
  - 唯一标识符
  - 块类型（视频、文本、测验、讨论等）
  - 块数据（JSON）
  - 块元数据（显示名称、排序）

- 结构树（Structure）
  - 根节点引用
  - 节点关系（父子、兄弟）
  - 版本号

- 内容库（ContentLibrary）
  - 库标识
  - 权限配置
  - 内容集合

**核心块类型**
| 类型 | 描述 | 关键属性 |
|------|------|----------|
| 视频（Video） | 视频播放器 | 视频URL、字幕、转录 |
| 文本（HTML） | 富文本内容 | HTML内容 |
| 问题（Problem） | 测验/作业 | 问题类型、评分答案 |
| 讨论（Discussion） | 嵌入式讨论区 | 主题配置 |
| 单元（Unit） | 内容容器 | 可见性设置 |
| 序列（Sequential） | 小节容器 | 导航设置 |
| 章节（Chapter） | 章节容器 | 时间安排 |

**外部依赖**
- 课程域（归属课程）
- 存储服务（文件/CDN）

**非职责**
- 不负责内容访问控制
- 不负责用户进度跟踪
- 不负责成绩计算

---

### 2.4 注册域（Enrollment Domain）

**领域目的**
管理用户与课程之间的注册关系和访问权限。

**关键行为**
| 行为 | 输入 | 输出 | 前置条件 |
|------|------|------|----------|
| 注册课程 | 用户+课程+模式 | 注册记录 | 课程开放中 |
| 取消注册 | 注册ID | 取消确认 | 已注册 |
| 升级模式 | 用户+课程+新模式 | 更新记录 | 已注册 |
| 验证资格 | 用户+课程 | 资格状态 | 已注册 |
| 批量注册 | 用户列表+课程 | 批量结果 | 管理员 |
| 恢复注册 | 用户+课程+会员 | 恢复记录 | 存在会员 |

**拥有数据**
- 注册记录（CourseEnrollment）
  - 用户ID
  - 课程ID
  - 注册模式（audit/verified/professional）
  - 激活状态
  - 创建/修改时间

- 课程模式（CourseMode）
  - 模式名称
  - 价格
  - 证书类型
  - 有效期

- 会员资格（CourseEntitlement）
  - 用户ID
  - 课程ID
  - 到期时间
  - 状态（活动/过期/已使用）

- 注册属性（EnrollmentAttribute）
  - 注册ID
  - 属性键
  - 属性值

**外部依赖**
- 商业域（验证支付）
- 课程域（验证课程存在）

**非职责**
- 不负责用户认证
- 不负责内容存储
- 不负责成绩计算

---

### 2.5 成绩域（Grades Domain）

**领域目的**
管理学习评估、成绩计算和历史记录。

**关键行为**
| 行为 | 输入 | 输出 | 前置条件 |
|------|------|------|----------|
| 提交答案 | 用户+内容+答案 | 提交记录 | 已注册 |
| 自动评分 | 提交记录 | 分数 | 已提交 |
| 手动评分 | 提交记录+分数+反馈 | 批改结果 | 评分权限 |
| 计算成绩 | 用户+课程 | 成绩记录 | 有提交 |
| 覆盖成绩 | 原成绩+新成绩+原因 | 覆盖记录 | 评分权限 |
| 获取成绩 | 用户+课程 | 成绩详情 | 已注册 |

**拥有数据**
- 小节成绩（PersistentSubsectionGrade）
  - 用户ID
  - 课程ID
  - 内容块ID
  - 得分/总分（全部）
  - 得分/总分（计入成绩）
  - 首次尝试时间
  - 课程版本

- 课程成绩（PersistentCourseGrade）
  - 用户ID
  - 课程ID
  - 百分比成绩
  - 字母等级
  - 通过时间
  - 评分策略哈希

- 成绩覆盖（PersistentSubsectionGradeOverride）
  - 用户ID
  - 课程ID
  - 内容块ID
  - 覆盖原因
  - 覆盖人

**外部依赖**
- 内容域（获取评分配置）
- 注册域（验证注册状态）
- 用户域（关联用户）

**非职责**
- 不负责内容存储
- 不负责证书生成
- 不负责通知发送

---

### 2.6 证书域（Certificate Domain）

**领域目的**
管理课程完成后的证书生成、颁发和验证。

**关键行为**
| 行为 | 输入 | 输出 | 前置条件 |
|------|------|------|----------|
| 生成证书 | 用户+课程 | 证书记录 | 成绩通过 |
| 下载证书 | 证书ID | PDF文件 | 证书有效 |
| 验证证书 | 证书UUID | 验证结果 | 证书存在 |
| 撤销证书 | 证书ID+原因 | 撤销记录 | 管理员权限 |
| 补发证书 | 用户+课程 | 新证书 | 历史记录 |

**拥有数据**
- 证书记录（GeneratedCertificate）
  - 用户ID
  - 课程ID
  - 状态（生成中/可用/已撤销/已过期）
  - 证书模式
  - 成绩
  - 下载URL
  - 验证UUID
  - 颁发日期

- 证书白名单（CertificateAllowlist）
  - 用户ID
  - 课程ID
  - 原因

- 证书配置（CertificateTemplate）
  - 模式
  - 模板内容
  - 签名配置

**外部依赖**
- 成绩域（验证通过）
- 存储服务（PDF存储）

**非职责**
- 不负责成绩计算
- 不负责用户认证
- 不负责课程配置

---

### 2.7 讨论域（Discussion Domain）

**领域目的**
管理课程讨论区的帖子、评论和社区互动。

**关键行为**
| 行为 | 输入 | 输出 | 前置条件 |
|------|------|------|----------|
| 创建帖子 | 用户+课程+标题+内容 | 帖子 | 已注册 |
| 编辑帖子 | 帖子ID+新内容 | 更新后帖子 | 作者/管理员 |
| 删除帖子ID | 删除帖子 | 确认 | 作者/管理员 |
| 回复帖子 | 用户+帖子+内容 | 评论 | 已注册 |
| 点赞内容 | 用户+目标 | 点赞记录 | 已注册 |
| 标记答案 | 提问者+评论 | 标记结果 | 帖子作者 |
| 搜索讨论 | 关键词+过滤 | 结果列表 | 已注册 |
| 举报内容 | 用户+内容+原因 | 举报记录 | 已注册 |

**拥有数据**
- 帖子（Thread）
  - 唯一标识
  - 课程ID
  - 作者ID
  - 标题
  - 内容
  - 类型（讨论/问答）
  - 状态（可见/删除/隐藏）
  - 投票数
  - 评论数
  - 是否已解答

- 评论（Comment）
  - 唯一标识
  - 帖子ID
  - 父评论ID（支持嵌套）
  - 作者ID
  - 内容
  - 投票数

- 讨论配置（CourseDiscussionSettings）
  - 课程ID
  - 允许的帖子类型
  - 是否需要审核
  - 分组设置

**外部依赖**
- 用户域（获取作者信息）
- 通知域（发送新回复通知）

**非职责**
- 不负责内容存储
- 不负责成绩计算
- 不负责证书生成

### 2.8 通知域（Notification Domain）

**领域目的**
管理用户通知的创建、分发和用户偏好设置。

**关键行为**
| 行为 | 输入 | 输出 | 前置条件 |
|------|------|------|----------|
| 发送通知 | 通知类型+收件人+内容 | 通知记录 | 系统事件 |
| 获取通知 | 用户+过滤器 | 通知列表 | 已认证 |
| 标记已读 | 通知ID | 更新确认 | 通知存在 |
| 设置偏好 | 用户+应用+偏好 | 保存结果 | 已认证 |
| 发送邮件 | 通知+收件人 | 发送确认 | 已配置 |
| 批量发送 | 通知+用户列表 | 发送报告 | 系统任务 |

**拥有数据**
- 通知（Notification）
  - 用户ID
  - 课程ID（可选）
  - 应用类型（讨论/成绩/更新）
  - 通知类型
  - 内容上下文
  - 各渠道状态（web/email/push；v1 仅 web）
  - 阅读时间
  - 查看时间

- 通知偏好（NotificationPreference）
  - 用户ID
  - 应用类型
  - 通知类型
  - 渠道启用状态（web/email/push；v1 仅 web）
  - 邮件频率

- 批量邮件（CourseEmail）
  - 课程ID
  - 发送者
  - 收件人群体
  - 邮件内容
  - 发送状态

**外部依赖**
- 邮件服务
- 推送服务（移动端）

**非职责**
- 不负责用户认证
- 不负责内容存储
- 不负责成绩计算

**外部依赖**

**非职责**

### 2.11 实验域（Experiments Domain）

**关键行为**
| 行为 | 输入 | 输出 | 前置条件 |
|------|------|------|----------|

| 获取实验数据 | 用户+实验ID | 实验数据 | 已分组 |
| 设置实验配置 | 实验ID+配置 | 保存结果 | 管理员 |

| 获取变体 | 用户+实验ID | 变体标识 | 已分组 |

**拥有数据**
- 实验配置（ExperimentConfiguration）
